# SPIN CITY: PING-PONG

Оригинальная неоновая аркада настольного тенниса: **TypeScript + Vite + Phaser 3**, собственная физика X/Y/Z, одиночная мировая лига и устанавливаемая офлайн-PWA.

Репозиторий: <https://github.com/mfdooom1-ctrl/ping-pong>.

Адрес **после успешного развёртывания GitHub Pages**: <https://mfdooom1-ctrl.github.io/ping-pong/>. Наличие этой ссылки в README само по себе не означает, что Pages уже включён: проверьте последний запуск Actions.

## Запуск

Нужен Node.js 22+.

```bash
npm ci
npm run dev
```

Открыть **http://localhost:5173/ping-pong/**. Для доступа с другого устройства сервер слушает `0.0.0.0`. Service Worker включается только в production-сборке; для установки PWA на iPhone необходим HTTPS.

```bash
npm run build
npm run preview
```

Открыть **http://localhost:4173/ping-pong/**. `localhost` подходит для проверки Service Worker на компьютере; обычный HTTP-адрес локальной сети на iPhone не заменяет HTTPS.

## Публикация в GitHub Pages

1. Откройте **Settings → Pages** репозитория `mfdooom1-ctrl/ping-pong`.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Выполните push в `main` либо вручную запустите **Actions → Build, test and deploy Spin City → Run workflow**.
4. Workflow установит зависимости по lockfile, проверит TypeScript, модульные тесты, production-ресурсы и браузерные сценарии, затем опубликует `dist`.
5. Откройте URL, который вернёт job **deploy**. Первый запуск может потребовать подтверждения environment `github-pages`, если у репозитория настроены правила защиты.

Workflow находится в [`.github/workflows/pages.yml`](.github/workflows/pages.yml). Он не требует токенов в исходниках. Используются стандартные `GITHUB_TOKEN`, `pages: write`, `id-token: write`.

**Приватный репозиторий:** доступность GitHub Pages зависит от тарифа и настроек аккаунта/организации. Если Settings сообщает, что Pages недоступен, используйте тариф с поддержкой Pages для приватных репозиториев либо самостоятельно измените видимость репозитория. Игра не меняет видимость и права доступа. Если интеграция разработки получает `403` от API Pages, включить Source в Settings должен владелец репозитория.

### Размещение в подпапке

По умолчанию `base` равен **`/ping-pong/`**, в соответствии с именем этого репозитория. Все графические ресурсы и Service Worker загружаются относительно `import.meta.env.BASE_URL`. `start_url`, `scope`, `id` и иконки manifest используют относительные адреса.

При переименовании репозитория измените `VITE_BASE_PATH` в workflow и команду/URL браузерных тестов. Для сайта в корне домена:

```bash
VITE_BASE_PATH=/ npm run build
VITE_BASE_PATH=/ npm run preview
```

Не открывайте `dist/index.html` через `file://`: нужны HTTP(S) и корректный base path.

## Установка на iPhone 17 Pro

1. В **Safari** откройте HTTPS-адрес Pages после успешного job `deploy`.
2. Дождитесь меню и сообщения **OFFLINE READY**: все обязательные ресурсы загружены в кэш.
3. Нажмите **Поделиться → На экран «Домой»**. Если Safari предлагает **Открывать как веб-приложение**, включите эту настройку.
4. Запустите SPIN CITY с новой иконки и поверните телефон горизонтально.
5. Нажмите **START GAME**, чтобы разрешить Web Audio. Выберите героя, арену и соперника.
6. После первого полного кэширования закройте приложение, включите авиарежим и повторно откройте его с иконки: матч и кампания доступны без сервера.

Ориентация не блокируется принудительно. В portrait показывается экран поворота, активный матч ставится на паузу. Компоновка учитывает `100dvh`, `safe-area-inset-*`, Dynamic Island и реальные CSS-размеры окна, а не физическое число пикселей. В landscape Canvas занимает весь динамический viewport; камера расширяет обзор без искажения пропорций. HUD остаётся в центральной безопасной области, зона жестов доходит до края экрана.

Safari может удалить кэш или localStorage при нехватке места или очистке данных сайта. Обязательных аккаунтов и серверного хранения нет.

## Управление

**Два больших пальца:**

| Зона | Действие |
| --- | --- |
| Левая | Необязательная ручная коррекция позиции. По умолчанию ноги автоматически следуют к прогнозируемому контакту. |
| Правая: короткое касание | Контролируемый flat drive независимо от меню. Также начинает свою подачу. |
| Правая: свайп вверх / вниз | Topspin / backspin. |
| Правая: свайп влево / вправо | Левое / правое боковое вращение. |
| Правая: диагональ | Совмещает верхнее/нижнее и боковое вращения. |
| Правая: длинный быстрый свайп | Повышенная мощность и риск; короткий медленный жест выполняет укороченный удар. |
| `SMASH!` | Доступен, когда входящий мяч достаточно высок. Нажимайте непосредственно перед контактом. |
| `FLAT DRIVE ▾` | Открывает все 17 ударов. При выборе арсенала игра приостановлена. |
| `SERVE: … ↻` | Переключает восемь видов подачи для следующего ввода мяча. |

В начале подачи есть физический подброс, затем удар: мяч сначала отскакивает от своей половины, затем от чужой. Подача, коснувшаяся сетки и правильно приземлившаяся, переигрывается.

В OPTIONS доступны EASY ASSIST, PRO и MANUAL независимо от сложности ИИ. EASY буферизует намерение до 620 мс и помогает с таймингом до 420 мс, PRO — 320/240 мс, MANUAL — 200/180 мс без автоподхода. Физический радиус мяча и досягаемость ракетки не увеличиваются. TRAINING содержит подсказки, продвигающиеся по действиям игрока. Длинный быстрый свайп вверх — атака; обычный вверх — топспин, вниз — подрезка, вбок/по диагонали — боковое вращение. Направление по горизонтали задаёт цель на столе.

Удар выполняется, когда мяч пересекает плоскость ракетки и находится в реальной досягаемости игрока. Короткий буфер ввода позволяет подготовить замах. Ориентир в ROOKIE и обучении — светящееся кольцо контакта и маркер ожидаемого отскока. PERFECT / GOOD / EARLY / LATE / MISS зависят от времени ввода, а не случайной оценки.

**Фирменные приёмы:** удержание почти до полного заряда у Джонни включает **MUSTACHE MAYHEM**; у Тони полный заряд с диагональным свайпом — **RICCIO TWISTER**. Меняются мощность и вращение, появляется короткий акцент и название. У соперников фирменный профиль периодически включается в длинных розыгрышах; ошибки всё равно определяются физикой и досягаемостью.

**Клавиатура:** WASD / стрелки — движение; Space — выбранный удар / подача; J — topspin; K — chop; U/I — sidespin; L — lob; O — drop; B — block; F — flick; M — smash; C — counterspin; E — emergency save; P/Escape — пауза; обратная кавычка — debug.

В **OPTIONS** доступны чувствительность, размер зон, леворукий режим, перестановка управления, помощь позиционирования, ручной forehand/backhand, музыка, эффекты, громкость и необязательная вибрация. На iPhone поддержка Vibration API не предполагается. Сложность и длина партии применяются к следующему матчу.

## Что есть в игре

- Два основных героя по визуальным референсам: Джонни с повязкой, длинными волосами, усами и формой USA; Тони с кудрями, mullet, усами и полосатым поло. Портреты и спрайты нарисованы для проекта, логотипы с фотографий не переносились.
- 12 соперников с отдельными параметрами и тактиками: углы, короткая игра, агрессивные петли, контратака, силовой удар, быстрый выход к столу, риск, обман, защита, ритм и смена темпа. ИИ прогнозирует ту же физическую траекторию, по которой летит реальный мяч, и двигается с ограниченной скоростью.
- ROOKIE / PRO / LEGEND изменяют время реакции, погрешность чтения вращения и передвижение ИИ. Физика мяча одинакова.
- 17 ударов, восемь подач, Magnus, сопротивление воздуха, угловая скорость, сцепление со столом, изменение вращения при отскоке, кромка, сетка и пол.
- 12 процедурно нарисованных пиксельных арен с разными палитрами, столами и декорациями: казино, крыша, Times Square, Miami, Tokyo, Dragon Club, Belgrade, motel, arcade, warehouse, penthouse, rainy alley. Коэффициенты стола одинаковы на всех аренах.
- Девять состояний анимации по четыре кадра у всех 14 персонажей: idle, move, windup, forehand, backhand, block, miss, victory, defeat — **504 кадра**. Удар справа/слева выбирается по относительному положению мяча или вручную.
- Оригинальный локальный пиксельный шрифт, 14 портретов, иконки и маскируемая иконка PWA. Фотографии не используются в игровой сцене.
- Web Audio: 13 оригинальных мотивов, темпы 128–166 BPM, мелодия, бас, арпеджио и ударные, комбинации тем арены/соперника, изменение плотности в длинном розыгрыше, победная и проигрышная фразы, звуки ракетки, стола, сетки, smash, spin, публика и короткие комические синтезированные вокальные акценты.
- Счёт до 5 / 7 / 11, преимущество в два очка, смена подающего через два очка и через одно на deuce. Один матч — одна партия.
- Автоматическая пауза на `visibilitychange`, `blur`, `pagehide` и при переходе в portrait. Возврат к матчу требует явного продолжения. Звук приостанавливается вместе с приложением.

### Режимы и прогресс

- **QUICK MATCH** — герой, соперник, открытая арена, сложность и длина партии.
- **ARCADE STORY** — 12 последовательных глав с репликами соперников и открытием локаций. Прогресс не требует сети.
- **TOURNAMENT** — восемь участников, четвертьфинал, полуфинал и финал. Другие встречи рассчитываются по характеристикам ИИ, с реальными итоговыми счетами; в следующую пару проходит победитель. Сетка сохраняется с незавершённым матчем.
- **TRAINING** — свободная игра, восемь подач, topspin, backspin и чередование forehand/backhand; 68% скорости времени, защитный тренер и подсказки траектории. Очки учитываются для обратной связи, матч не заканчивается.
- **CHALLENGES** — восемь своих возвратов в одном розыгрыше, шесть подкрученных возвратов, пять PERFECT, три smash и восемь видов легальной подачи. Возврат засчитывается после правильного отскока на чужой половине.
- Победы дают клубные очки и постепенно открывают персонажей, альтернативные цветовые комплекты формы и декоративные ракетки. Косметика меняет спрайт, не физику. Начальные арены: Vegas, rooftop, Miami и arcade; остальные открываются в Story.
- Матч автоматически сохраняется примерно раз в две секунды, а также при паузе и сворачивании. **CONTINUE SAVED MATCH** восстанавливает мяч, вращение, счёт, фазу подачи и турнирную сетку, начиная с паузы. Прогресс и настройки имеют отдельное сохранение.

Преступные лиги и группировки — художественная условность отдельных персонажей; национальность не является признаком преступности.

**LOCAL 2 PLAYER** отложен: удобство такого управления на одном телефоне не проверено. Мультиплеер, реальные голоса актёров, сетевые таблицы рекордов и платные покупки не включены.

## Проверки

```bash
npm run check
npm test
npm run build
npm run test:assets
npx playwright install chromium
npm run test:browser
```

Или `npm run verify`, если Chromium уже установлен. На Linux можно использовать системный Chromium; `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium` выбирает бинарник явно. В CI устанавливается Chromium из Playwright. Проверки production-сборки и браузера предполагают base `/ping-pong/`.

Модульные тесты проверяют полёт, Magnus, вращение, сцепление и отскоки, быстрые столкновения без пролёта сквозь поверхность, все восемь подач с обеих сторон, траектории всех 17 ударов, правила подачи и deuce, сохранения, ИИ, живой розыгрыш, паузу и турнирную сетку. `test:assets` сверяет каждый ресурс сборки с precache и проверяет относительные пути manifest и production base.

Браузерные проверки: меню → матч → физическая подача → настоящее очко, пауза/продолжение/перезапуск, арсенал и подачи, запуск режимов, восстановление после reload, полный запуск и игра при отключённой сети, мультитач через CDP и portrait-подсказка. Мобильный viewport **874×402 CSS px, DPR 3** проверяется в эмуляции Chromium. Это **не проверка реального iPhone или Safari**.

На устройстве ещё требуется проверить: 60/120 Hz под нагрузкой и нагревом, точность управления двумя пальцами, задержку звука, прерывания звонком, поведение установленной PWA после перезагрузки iOS, Dynamic Island/safe areas и длительное сохранение кэша. Целевой рендер использует `requestAnimationFrame`, до 120 кадров при поддержке браузером; физика всегда 120 Hz. Стабильные 60/120 FPS на конкретном iPhone без такого замера не заявляются.

## Устройство проекта

```text
src/game/scenes/       Phaser, проекция, арены, анимация и эффекты
src/game/physics/      X/Y/Z, непрерывные пересечения, правила, симуляция матча
src/game/characters/   описание формата оригинальных кадров
src/game/ai/           прогноз отскока, тактики, ограниченное движение
src/game/input/        Pointer Events, отдельные pointer IDs, жесты и клавиатура
src/game/audio/        оригинальный многоголосный Web Audio sequencer
src/game/ui/           меню, HUD, пауза, режимы и настройки
src/game/data/         соперники, арены, удары, сохранения, турнир
src/pwa/              регистрация и уведомления об обновлениях
public/assets/        локальные PNG, atlas JSON, TTF и PWA-иконки
scripts/              исходник генерации авторской графики и проверка сборки
tests/                Vitest и Playwright
```

Физические коэффициенты — `src/game/physics/config.ts`. Один фиксированный шаг — `1/120` секунды; отрисовка не определяет скорость симуляции. Прогноз ИИ использует копию мяча и ту же интеграцию, не меняет состояние настоящего мяча. При сильной задержке кадра время ограничивается, чтобы не накапливать бесконечный backlog. Очень высокие свечи визуально сжимаются по высоте, чтобы мяч оставался в видимой области; его реальные координаты не меняются.

Графика воспроизводится командой `python3 scripts/generate-art.py` с Pillow и fontTools. Генерированные файлы уже находятся в Git; Python не требуется для обычной сборки. Музыка и эффекты синтезируются из локального TypeScript-кода; обязательных внешних CDN и аудиофайлов нет.

### Обновление офлайн-версии

Новый production build получает отдельный кэш по хешам ресурсов. Service Worker сначала целиком предзагружает новую версию; неактивированное обновление не заменяет текущую игру посреди матча. В **OPTIONS → CHECK FOR UPDATE** можно установить ожидающую версию с перезагрузкой. Предыдущие кэши этого scope удаляются при активации. Сохранения localStorage сохраняются при обновлении; очистка данных сайта удалит их.

Debug выключен по умолчанию. Включается в OPTIONS, клавишей обратной кавычки или параметром `?debug`. Показывает FPS, координаты, скорость, вектор вращения, прогноз отскока и текущую задачу ИИ. `window.__SPIN_CITY__.getState()` возвращает диагностический снимок для тестов; методов принудительного начисления очков нет.
