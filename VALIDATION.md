# Проверка сборки 1.0.0

Дата: 9 ноября 2026. Среда: Linux, Node.js 24.22.1, Chromium 156.0.8078.79, Playwright 1.65.0. Точные разрешённые версии зависимостей закреплены в `package-lock.json`; версии системного Chromium и Playwright можно сверить командами `chromium --version` и `npx playwright --version`.

Команда `npm run verify` завершилась успешно:

| Проверка | Результат |
| --- | --- |
| TypeScript strict / `tsc --noEmit` | Пройдено |
| Vitest | **81 / 81** |
| Production build / base `/ping-pong/` | Пройдено |
| Precache и ссылки production-ресурсов | **26 ресурсов**, 6 HTML-ссылок, все файлы найдены |
| Playwright / Chromium | **8 / 8** |

Проверенные браузерные сценарии:

1. Меню, матч, настоящая подача, физически заработанное очко, пауза, продолжение и сброс счёта при перезапуске.
2. Доступность всех 17 ударов и восьми настроек подачи.
3. Реальные возвраты с клавиатуры, несколько контактов в одном розыгрыше, запуск Web Audio и движение музыкального секвенсора после жеста.
4. Запуск Story, Training, Tournament и Challenges в настоящую игровую сцену.
5. Настройки, сохранённый мяч, счёт и восстановление после перезагрузки с обязательной паузой.
6. Полное кэширование, отключение сети, reload, запуск матча и подача офлайн.
7. Два одновременных touch pointer: движение стиком и отпускание правого пальца для подачи. Viewport 874×402 CSS px, DPR 3. Проверены минимальные размеры кнопки паузы.
8. Экран поворота в portrait 402×874.

Модульная симуляция отдельно подтвердила розыгрыш минимум из восьми реальных контактов с ракетками без принудительного изменения счёта или координат. Все восемь подач с обеих сторон последовательно попадают на свою и чужую половину. Все 17 профилей удара в нормальных исходных условиях перелетают сетку и попадают на противоположную половину.

Во время разработки исправлены: неверный base локального production preview, несовпадение кэша по `Vary: Origin`, перекрытая кнопка продолжения, отрисовка мяча под ближним персонажем и несоответствие теста времени симуляции замедленному Training. Повторные проверки после исправлений прошли.

## Границы проверки

- Физического iPhone 17 Pro и iOS Safari в этой среде нет. Установка из Safari, звонки, safe areas в standalone, нагрев и стабильные 60/120 FPS на устройстве не подтверждены.
- Дополнительная попытка запуска Linux WebKit остановилась до тестирования: в среде отсутствуют `libgtk-4`, `libgraphene`, `libharfbuzz-icu`, `libmanette`, `libhyphen`, `libGLESv2`. Chromium-проверки не заменяют Safari/WebKit.
- Долгосрочный баланс 12 соперников, ощущение тайминга на физическом сенсорном экране и музыкальный баланс требуют игрового тестирования людьми.
- До отправки кода GitHub API сообщал `has_pages: false`; API управления Pages возвращал `403 Resource not accessible by integration`. Локальные проверки не доказывают публикацию на Pages. Итог GitHub Actions следует проверять отдельно.
- LOCAL 2 PLAYER намеренно не включён, как допускает исходное задание.
